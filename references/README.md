# References

디자인 시스템 구체화 및 사이트 개편 과정에서 참고하는 자료 보관 공간입니다.

## 폴더 구조

```
references/
├── design/       # 참고할 사이트, 블로그, 포트폴리오 링크 및 메모
├── colors/       # 색상 팔레트 레퍼런스
├── fonts/        # 폰트 레퍼런스
└── ui-patterns/  # UI 컴포넌트, 레이아웃 패턴 참고 자료
```

## 사용 방법

- 각 폴더에 `.md` 파일로 메모 + 링크 정리
- 스크린샷 등 이미지는 해당 폴더 안에 함께 보관
- AI에게 작업 지시 시 "references/ 참고해서 ..." 형태로 활용
