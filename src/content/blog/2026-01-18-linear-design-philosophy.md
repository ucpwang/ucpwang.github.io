## "Calm Interface"란 무엇인가

Linear의 디자인 팀은 자신들의 UI를 "Calm Interface"라고 부른다. 조용한 인터페이스. 이게 무슨 뜻인가?

> "The interface should fade into the background, letting your work take center stage."
> — Linear Design Team

인터페이스가 배경으로 물러나고, 콘텐츠(작업)가 전면에 나선다는 개념이다.

## 구체적인 구현 원칙

### 1. 모든 픽셀이 이유가 있어야 한다

Linear의 UI에는 장식적인 요소가 거의 없다. 그라디언트, 화려한 아이콘, 불필요한 테두리 — 전부 제거했다.

"이 요소가 없으면 사용자가 혼란스러운가?" 이 질문에 "아니오"면 지운다.

### 2. 딥 다크 배경

밝은 배경은 눈을 피로하게 만든다. Linear는 `#0f0f0f`에 가까운 딥 블랙을 기본 배경으로 쓴다.

흥미로운 건, 이 배경색이 OLED 디스플레이에서 전력 절약 효과도 있다는 점이다.

### 3. 색상 절제

Linear의 UI에서 색상은 **상태 전달**에만 쓴다. 빨강 = 오류, 초록 = 완료, 보라 = 브랜드(링크, CTA). 장식적 색상 사용은 없다.

```css
/* Linear 접근법 */
.status-done {
  color: #26c940;
} /* 의미가 있는 색상 */
.status-todo {
  color: #a0a0a0;
} /* 중립 */

/* 지양하는 접근법 */
.heading {
  color: #6366f1;
} /* 그냥 예쁘라고 */
```

### 4. 8px 스페이싱 스케일

모든 여백은 8의 배수다. 4, 8, 16, 24, 32, 40, 48...

이 시스템이 있으면 "여기 여백이 얼마지?" 고민이 사라진다. 8의 배수 중 가장 적절해 보이는 걸 고르면 된다.

### 5. Inter 타이포그래피

Linear는 Inter 폰트 하나만 쓴다. 서로 다른 폰트 페어링을 고민할 필요가 없다. 대신 **웨이트와 크기**로 계층을 만든다.

## 이 철학에서 배울 것

개인 블로그에 적용할 수 있는 핵심:

1. **색상을 줄여라**: 브랜드 컬러 하나, 텍스트 3단계(primary/secondary/muted)로 충분하다
2. **여백을 아끼지 마라**: 정보 밀도를 줄이면 중요한 것이 돋보인다
3. **폰트는 하나**: Pretendard 하나로 제목부터 본문까지. 페어링 고민 불필요
4. **장식 제거**: 그라디언트, 불필요한 아이콘, 화려한 배경 이미지 — 없애면 오히려 프리미엄해 보인다

## 역설: 비워서 채운다

Linear의 가장 큰 교훈은 역설적이다. 덜 넣을수록 더 전문적으로 보인다. 이는 자신감의 표현이기도 하다.

많은 걸 보여주려는 충동을 억제하고, 정말 중요한 것만 남기는 것 — 이게 "Calm Interface"의 핵심이다.

내 블로그도 이 방향이다. 포스트가 전면에 나서고, UI는 조용히 뒤로 빠지는 것.
